for the security team. hello. i know you're reading this.

what it does
goes fullscreen, waits, talks, asks to be locked.
what it sends
nothing. after this page has loaded it makes zero requests. the content security policy forbids it, so it couldn't if it wanted to.
what it stores
one number on this laptop: how many times it has been caught. it never leaves the machine.
what it reads
nothing. keys are counted, never read. the only keys it looks at are esc and the right arrow.
what it can't do
touch files, see the screen, block esc, keep the machine awake or stop it from locking.
who can see you
github hosts this page and sees the request for it, like any web host. we don't get those logs.
how to check
open devtools. arm it. watch the network tab do nothing. or read the source. it's short.
